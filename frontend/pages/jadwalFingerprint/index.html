Jadwal Fingerprint

Jam kehadiran pengurus dihitung otomatis dari scan alat fingerprint. Kolom bisa dikoreksi manual kalau alat sedang bermasalah -- sel yang dikoreksi ditandai warna berbeda.

Pengaturan Bridge Fingerprint

Kunci ini dipakai script bridge lokal (tools/fingerprintBridge) untuk autentikasi saat mengirim data scan ke server. Salin nilai ini ke file .env script bridge, isi FINGERPRINT_BRIDGE_KEY. Tidak dipakai kalau alat memakai jalur ADMS push langsung.

Status Koneksi Alat

Cek apakah alat sudah pernah berhasil menghubungi server ini -- terlepas dari ID pengurus di alat sudah benar atau belum.

Scan PIN Tidak Dikenal

Scan mentah dari alat yang PIN-nya tidak cocok id_pengurus manapun -- tetap tersimpan ke database, tapi tidak ikut muncul di tabel jadwal di atas karena tidak bisa dikaitkan ke pengurus mana pun. Cek di sini kalau ada PIN yang salah setting di alat.
